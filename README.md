# 🚀 v2.0 重大架构升级说明 (2026-10-22)

相比昨日的 MVP (最小可行性产品) 版本，本次更新完成了从“单体脚本”向“企业级全栈智能体系统”的全面演进：

## 1. 前端架构彻底重构 (React + Ant Design)
- **抛弃原生 HTML**：使用 Vite 搭建了标准化的 React 单页应用 (SPA)。
- **企业级 UI 规范**：引入 Ant Design 组件库，构建了包含左侧导航栏、Header 头部和主内容区的现代化 B 端后台布局。
- **页面级路由管理**：引入 `react-router-dom`，实现了“智能审查”与“系统架构”页面的无缝切换。
- **富文本渲染**：引入 `react-markdown`，完美解析大模型返回的 Markdown 格式（加粗、列表），修复了原生 HTML 标签截断问题。

## 2. 混合知识引擎升级 (真实 RAG 落地)
- **替换虚假字典**：彻底废弃硬编码的字典数据，引入 **ChromaDB** 本地向量数据库。
- **向量化检索**：接入智谱 Embedding 模型，将 `policy.txt` 制度文档切片并向量化存储。检索时基于语义相似度精准召回相关条款，彻底消除大模型幻觉，实现了真正的 RAG（检索增强生成）。

## 3. 多智能体协作编排 (LangGraph)
- **引入 LangGraph**：构建了基于状态图 (StateGraph) 的多智能体协作网络。
- **角色解耦**：系统内划分为“审批 Agent”（负责算账与查制度）与“打款 Agent”（负责生成财务凭证）。
- **自动流转**：当审批结果判定为合规时，状态机自动触发打款 Agent 接管，生成带有随机 UUID 的打款单号。

## 4. 流式体验与 Bug 修复
- **SSE 流式输出优化**：修复了网络切片导致的汉字乱码问题，重写了 `ReadableStream` 解析逻辑。
- **剥离思考过程**：通过 `astream_events` 精准捕获事件，过滤了 LangChain 的中间思考步骤（Thought/Action），避免前端出现重复生成和幻觉文本。
- **UI 细节打磨**：修复了 Flex 布局导致的头像拉伸问题，优化了聊天气泡的自动换行与色彩搭配。
